End-to-End System

자료는 청크 분할 후 SQLite FTS5에 저장되고, 질문 시 스마트 라우팅으로 컨텍스트를 조합해 Groq(llama-3.3-70b)가 답변.
체류 시간은 Personal_Log에 기록되고, /log 엔드포인트로 수집된다.

Ingest Pipeline — Cookie → SQLite

JSESSIONID 하나로 세션을 확립하고 KJKEY 단위로 과목 컨텍스트를 설정.
강의자료는 다운로드 → 텍스트 추출 → 페이지 단위 청크 분할 → Doc_Chunk 저장.
MD5 체크섬으로 재동기화 시 중복 저장을 방지. 활동은 동기화 전 clear_activities로 초기화해 e-Class와 일치를 보장.

Chat / RAG Flow — Smart Routing → Groq

질문 키워드를 분석해 과제/마감 질문이면 Learning_Activity를, 강의자료 질문이면 Doc_Chunk FTS5를 검색.
키워드 추출은 llama-3.1-8b-instant(토큰 절약), 최종 답변은 llama-3.3-70b-versatile(429 시 8b fallback).
활동 목록에는 D-day 태그를 Python에서 직접 계산해 삽입. 피드백(👍/👎)은 Chat_Log.feedback_score에 반영.
